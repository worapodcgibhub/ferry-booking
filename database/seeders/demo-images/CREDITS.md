# เครดิตภาพปกสาธิต

ภาพจริงจาก [Wikimedia Commons](https://commons.wikimedia.org/) ใช้เป็นภาพปกเกาะในข้อมูลสาธิต (`DatabaseSeeder` คัดลอกเข้า `storage/app/public/covers/`)
ใช้ซ้ำได้ตามสัญญาอนุญาต Creative Commons ด้านล่าง **ต้องให้เครดิตผู้ถ่าย** — ระบบแสดงเครดิตท้ายหน้าเว็บให้อัตโนมัติ
(ข้อมูลเครดิตอยู่ใน `config/ferry.php` คีย์ `cover_credits` และจะหายไปเองเมื่อเปลี่ยนภาพปกของเกาะนั้น)

## หมายเหตุ
- ไฟล์ในโฟลเดอร์นี้คือภาพขนาดย่อ (thumbnail) ที่ Wikimedia Commons สร้างให้จากภาพต้นฉบับ ไม่ได้แก้ไขเพิ่มเติม การครอบตัดทำด้วย CSS ตอนแสดงผลเท่านั้น
- CC BY-SA 3.0 (ภาพเกาะกูด) กำหนดให้ *งานดัดแปลงตัวภาพนั้น* ใช้สัญญาอนุญาตเดียวกัน ก่อนนำไปใช้งานจริงควรอ่านเงื่อนไขของสัญญาอนุญาตแต่ละฉบับตามลิงก์ด้านบน
- ถ้าจะใช้งานจริงเชิงพาณิชย์ ควรเปลี่ยนเป็นภาพที่เจ้าของโครงการถ่ายเองหรือซื้อลิขสิทธิ์ (อัปโหลดที่หน้าหลังบ้าน "เกาะและพื้นที่") แล้วเอาไฟล์และรายการเครดิตออก
